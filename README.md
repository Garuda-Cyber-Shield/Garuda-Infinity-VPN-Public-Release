## How to Install or Update

### 1. Android APK (`Garuda-Infinity.apk`)
1. Download [**`Garuda-Infinity.apk`**](./Garuda-Infinity.apk) on your Android phone.
2. Open the downloaded `.apk` file to install (or update in-place over your existing installation without losing settings).
3. Tap the central **Connect** button and approve the Android System VPN connection prompt.

### 2. Browser Extension (`Garuda-Infinity-Extension.zip`)
1. Download [**`Garuda-Infinity-Extension.zip`**](./Garuda-Infinity-Extension.zip) and extract it to a folder on your PC.
2. Open `chrome://extensions` (or `edge://extensions` / `brave://extensions`).
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the extracted folder.
